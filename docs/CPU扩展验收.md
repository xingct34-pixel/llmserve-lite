## 指标与复现

新增 http_requests_started、http_responses_logged、http_status_429/4xx/5xx。它们来自 HTTP handler/库响应日志；Scheduler completed 仅表示生成成功。SSE 流内错误可能仍对应 HTTP 200，底层连接失败未必产生日志，客户端结果仍是压测依据。

复现：`python3 bench/cpu_matrix.py --soak-seconds 600`。默认仅使用已有已校验模型，不下载。完整原始证据位于 results/cpu-matrix/；公开汇总见 docs/benchmarks/cpu-matrix.json。GPU、多模型、continuous batching、分布式、回答质量和 Docker 未验证。GitHub CI 仅覆盖 Mock/Sanitizer，真实测试在当前 WSL 执行。
