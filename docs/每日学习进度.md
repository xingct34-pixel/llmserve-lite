# 每日学习进度与顺序

更新：2026-11-12。此文档记录个人学习，不把自动开发、构建或测试成功当作本人已掌握。

## 固定制度

用户主动询问“今日任务”时，每天都安排两个项目：先YOLO，后LLMServe-Lite。默认一周五天，周六周日休息；总投入约3—4小时，根据当日理解及练习情况调整，不以刷完文件数量验收。

每个模块采用“指出GitHub具体文件和函数 → 用户阅读、提问并自行加注释 → 结合数据流解释 → 小型改动/排错练习 → 理解核验”。先补足练习必需的C++语法和变量含义，优先通俗例子，代码分小块并带说明。常规编译、测试由助手处理。避免重复简单问题或强制记笔记；结束时说明当天实际完成到哪里。

用户自己添加的注释必须保留。新增代码按模块前后各两行空行，并在模块开头标明名称和作用。新增开发功能不插入当前学习主线强行提前学习。
